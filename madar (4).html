تغییر رمز عبور مدیر

درباره دسترسی مدیریت

این پنل به یک سرور واقعی وصل است: رمز عبور به‌صورت هش‌شده روی سرور نگه‌داری می‌شود و هرگز داخل کد این صفحه یا مرورگر ذخیره نمی‌شود. نشست ورود شما با یک کوکی امن (httpOnly) کنترل می‌شود که پس از ۱۲ ساعت به‌صورت خودکار منقضی می‌گردد. اگر رمز عبور را فراموش کردید، باید از طریق فایل تنظیمات سرور (`.env` و دستور `npm run seed`) آن را بازنشانی کنید — به فایل README پروژه بک‌اند مراجعه کنید.
